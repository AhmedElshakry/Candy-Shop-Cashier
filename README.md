Candy Shop Cashier Project

Non-Representable Change Limitation:
The program calculates change using a greedy algorithm with fixed coin denominations: 500, 200, 100, 50, and 25 piastres. 
When a change amount leaves a remainder smaller than the smallest available coin (25 piastres)—such as 137 piastres, which leaves a remainder of 12 piastres after using 100 and 25—the system cannot represent those remaining piastres using the available coins. In this case, the program triggers a warning message indicating the exact unrepresented amount.
